# Research Memory

Markdown is source of truth. Git is file history. Obsidian is an optional view/lens.

## Commit
Only accepted or human-edited proposals enter persistent memory.

## Preserve
Stable IDs, provenance, source references, review status, timestamps, knowledge-state evolution, and research-question evolution.

## Safe mutation
Prefer patch-style updates. Do not rewrite entire notes when a targeted update is sufficient.

## Links
Use stable IDs for identity and human-readable Obsidian wiki links for navigation, e.g. `[[Mamba]]`, `[[WAVE-MAMBA]]`, `[[RQ-0005]]`, `[[EXP-0017]]`.

## Two histories
Keep file/Git history distinct from semantic research history.
