# Research Protocol v0.1

## Core rule

> AI proposes. Human validates. Repository remembers.

## Workflow

```text
DISCOVER → EXTRACT → PROPOSE → VALIDATE → ACCEPT / EDIT / REJECT → COMMIT → MEMORY
```

## Skill permission levels

- L0 Read
- L1 Propose
- L2 Human Commit
- L3 Controlled Mutation of an explicitly allowed field set

## Required Skill contract

Every Skill must define: inputs, readable entities, proposals, permitted mutations, forbidden mutations, and commit conditions.

## Provenance
Generated content is not verified knowledge. Committed entities preserve provenance and review status.

## Traceability
Evidence should point to page, section, figure, table, equation, code commit, or experiment log when possible.

## Human state
Do not infer the user's knowledge state as objective truth from a single conversation turn. Keep self-assessment, AI assessment, and verified evidence distinguishable.
